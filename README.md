💎 Project Overview

Prism Insurance Analysis is an end-to-end data analytics project developed as part of my learning journey through the Complete Data Analyst Bootcamp: From Basic to Advanced on Udemy.

The project explores insurance premiums, policy coverage, claims, and customer demographics to uncover meaningful patterns and support data-driven decision-making.

Using Microsoft SQL Server for data retrieval and Microsoft Power BI for interactive visualization, this project demonstrates how raw insurance data can be transformed into valuable business insights.

🚀 Business Recommendations

01 — Improve Claim Monitoring
Track pending claims by ageing category and establish processing targets.

02 — Investigate Claim Rejections
Record rejection reasons and identify recurring patterns that may require process improvements.

03 — Monitor Policy Performance
Compare premium contributions and claim trends across policy types.

04 — Strengthen Data Quality
Validate missing dates, zero claim amounts, duplicate records, and key identifiers before reporting.

05 — Expand the KPI Framework
Consider adding claim settlement rate, rejection rate, pending claim ageing, and average claim amount.
