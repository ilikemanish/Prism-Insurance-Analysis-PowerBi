🛡️ Prism Insurance Analysis Dashboard

📌 Project Overview

The Prism Insurance Analysis Dashboard is a data analytics project designed to analyze insurance premiums, coverage amounts, claim statuses, and customer demographics using Microsoft Power BI.

This project was developed as part of the Complete Data Analyst Bootcamp: From Basic to Advanced course on Udemy.

🎯 Project Objectives

- Analyze insurance premium and coverage trends.
- Track claim amounts and claim statuses.
- Compare premiums across different policy types.
- Understand customer demographics and claim patterns.
- Generate actionable business insights and recommendations.

🛠️ Tools and Technologies

- Microsoft SQL Server — Data Retrieval and SQL Queries
- Microsoft Power BI — Interactive Dashboard Development
- Power Query — Data Cleaning and Transformation
- DAX — KPI Development and Calculations
- Microsoft Excel / CSV — Source Data

💡 Business Recommendations

1. Monitor Pending Claims: Track pending claim age and establish service-level targets to reduce delays.
2. Analyze Rejected Claims: Introduce rejection reason codes to identify recurring problems.
3. Review Travel Insurance: Investigate the high premium contribution from travel policies.
4. Validate Data Quality: Check duplicate records and missing claim dates before reporting.
5. Improve KPI Tracking: Monitor settlement rate, rejection rate, average claim severity, and pending claim amounts.

⚙️ Project Workflow

1. Retrieve insurance data using SQL Server.
2. Clean and transform the data using Power Query.
3. Create measures and KPIs using DAX.
4. Build interactive visuals in Power BI.
5. Analyze trends and prepare business recommendations.
